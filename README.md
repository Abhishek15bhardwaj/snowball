# Snowball – DSSSB TGT Computer Science revision

Daily "snowball" revision: every switched-on subject comes back each day with shuffled questions and options, fresh numericals, mistakes tracking, and a DSSSB Section B mock (100 Q / 60 min).

- `index.html` – the app (no build step)
- `gens.js` – numerical question generators
- `banks/` – question banks and theory cards (DSSSB PYQs + syllabus top-ups)
- `config.js` – Supabase URL and anon key for syncing progress (passphrase-based)

Hosted with GitHub Pages from the `main` branch root.
